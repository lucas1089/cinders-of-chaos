# Visual das magias despertas
Date: 2026-11-22
Kind: news

As magias despertas têm um visual próprio agora. Com o novo cliente do jogo, uma magia desperta toca um efeito novo do seu elemento
ao ser lançada, com um anel de sigilo que gira enquanto toca, e o projétil dela também é novo.

Achou um bug? Use System > Report a Bug no jogo, ou conte para a gente no Discord. Toda denúncia é lida.

## Novidades

- **Um visual para cada magia desperta.** O efeito segue o elemento da magia e o formato dela: alvo único, círculo, um anel
  em volta de você, uma linha ou uma onda. Uma Forma que muda o elemento da magia muda o visual junto. Magias sem elemento
  próprio usam o visual arcano. Dano, área e tempo não mudam.
- **Precisa do cliente novo.** Atualize o cliente do jogo para ver. Um cliente antigo mantém os efeitos de sempre.
