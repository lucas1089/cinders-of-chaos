# Start here

1. Install Python 3.10+ and run `pip install -r requirements.txt`.
2. Open this folder in your AI coding agent and say:

   > Read AGENT_GUIDE.md and set up Map Studio with me.

3. Answer its questions: where your map and item files are, which map is your quality reference, which
   biomes you want, and how you'd like to pick items.
4. Look at what it shows you (item sheets, renders, review pages), and tell it what's wrong. It fixes the
   rules and shows you the next batch.

No agent? Read `README.md` (quick start) and `docs/STUDY_RECIPES.md`.
