# Cinders of Chaos logo
`cinders_logo.png` (transparent), `cinders_logo_black.png` (on black) and `cinders_logo_icon.png` (1024x1024 icon / avatar) are the logo cut out of the login artwork (`client/tools/art_src/login_reference.webp`).
Regenerate them with `python3 -I client/tools/gen_login_art.py brand` (needs opencv-contrib-python-headless and scipy).
